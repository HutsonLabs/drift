Drift — glass redesign

Static mockup for review. Same screens, same copy, same controls as today; new layout, Liquid Glass–style materials, and Avenir Next throughout. Toggle the appearance to check both modes.

1 · Connections

  • Window uses native vibrancy; the sidebar floats as an inset glass panel with the traffic lights sitting on it.
  • Each connection gets a colored mode glyph, host and live-session dot. Connect is a single play button on the selected row, not a button on every row.
  • The form becomes System Settings–style grouped rows: label left, control right.
  • Connection type is three tiles with icons; the selected mode’s explanation stays underneath.
  • Checkboxes become switches. Trust status moves into the header (“Certificate trusted”).
  • Save / Cancel / Delete float in a glass action bar that only appears when there are unsaved edits.

The Remote Login credentials set on the host with sudo grdctl --system rdp set-credentials. They open the GNOME login screen; you then log in with your own account.

2 · Connecting & trust

  • Connecting shows every stage as a checklist instead of one line of status text, so a stall is obvious.
  • The certificate prompt is a glass sheet: shield badge, fingerprint in a card, “Remember” as a switch.
  • Both sheets blur and dim the window behind them instead of replacing it.

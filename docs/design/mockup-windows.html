Drift — windows redesign

Static mockup for review. The tab strip is gone. Drift has one Connections window, a gallery of large cards where you pick and set up connections in a modal sheet, and one session window for each live connection. New connections start as a Headless session, then Desktop Sharing, then Remote Login. Same Liquid Glass materials and Avenir Next as the previous mockup.

0 · One window per connection

  • Connections is a single window. ⌘0 brings it forward from anywhere; closing it doesn’t end any sessions.
  • Connect on a card opens a new session window for that connection. Connecting again to a live one just brings its window forward.
  • Session windows are ordinary Mac windows: move them to other displays or Spaces, tile them, or use Mission Control and ⌘` to switch.
  • Closing a session window disconnects it (after a confirmation if it’s live). The card returns to its idle state.
  • Drift’s Dock menu lists every window with its live dot, so you can jump to a session without the Connections window.
  • Quitting with sessions open asks once for all of them.

1 · Connections window

  • Every saved connection is a large glass card: a 16:9 preview, mode glyph, name, host and mode.
  • Live connections show the session window’s latest frame and a Live pill; idle ones show their mode color and glyph, so the three kinds are easy to tell apart.
  • Open connections sort into their own row at the top. States: Live (green), Connecting (spinner), Reconnecting (amber), Failed (red).
  • Hover a card for one big action on the preview: Connect, or Show Window if it’s live. Double-click or ↩ does the same.
  • The ⋯ button opens Edit…, Duplicate, Disconnect and Delete. Edit opens the configuration sheet.
  • + in the toolbar, the dashed card, or ⌘N starts a new connection. The toolbar also has search and an All / Open filter.

2 · New connection sheet

  • A modal sheet over the gallery. The gallery stays visible, blurred and dimmed, so you keep your place.
  • Connection type defaults to Headless session. The tiles run Headless, Desktop Sharing, Remote Login, left to right.
  • Changing the type swaps only the credential section below it; name, host and port are kept.
  • Rarely changed options sit in a closed disclosure with a one-line summary of the current values.
  • The footer stays put while the body scrolls. Add & Connect is the default button (↩); Add just saves the card. esc cancels.
  • Errors show inline on the field, e.g. a missing host, and the default button stays disabled until they’re fixed.

3 · Editing a connection

  • Edit… opens the same sheet with the connection’s name, host, mode and trust status in the header, plus a Connect button.
  • Desktop Sharing points at GNOME Settings for its credentials and notes that it can’t resize the remote screen.
  • Remote Login adds the system RDP credentials and the GNOME login screen section.
  • Delete sits on the left of the footer, away from Save. Save stays disabled until something changes.
  • Editing a live connection is allowed; the sheet notes that changes apply the next time it connects.

4 · Connecting & trust

  • Connect opens the session window straight away and runs the stage checklist in it. The card shows a Connecting pill at the same time.
  • The certificate prompt is a sheet on the session window, so the Connections window stays usable while you check the fingerprint.
  • Closing the window or pressing Cancel stops the attempt; the window closes and the card goes back to idle.
  • The window title shows a spinner in place of the live dot until the desktop appears.

5 · Session window

  • No tab strip: the transparent title bar holds only the traffic lights, a centered identity capsule (mode glyph, name, live dot) and two buttons.
  • The grid button brings the Connections window forward (⌘0); the gauge toggles the statistics readout.
  • The window title is the connection name, so Mission Control, ⌘` and the Window menu all show it.
  • Greeter hint, statistics and reconnect ring work as before, but belong to this window alone.
  • Each window remembers its own size and position per connection.

6 · Full screen & menus

  • Each session window goes full screen into its own Space, so you swipe between remote desktops like any full-screen apps.
  • The Window menu lists Connections and every session with its glyph and live dot; ⌘1–⌘9 jump to sessions.
  • File has New Connection (⌘N), Show Connections (⌘0), Disconnect (⇧⌘D) and Close Window (⌘W, which disconnects).
  • When the remote desktop has the keyboard, Drift’s shortcuts still work.

7 · Errors

  • A failed connection keeps its window with the error sheet, a red dot in the title and a Failed pill on its card.
  • Actions stay the same: the first is primary and focused. Closing the window dismisses the failure.
  • Edit Connection… opens the configuration sheet on the Connections window, for errors that need a change there (wrong credentials, host).

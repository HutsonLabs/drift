# Drift
Drift is a rust-based Tauri app that allow an macos client to access gnome remote desktop on wayland using Gnome 50+

## Features
1. Full GDM/RDP connection
2. GPU-rendered frames
3. Keyboard + mouse + trackpad scroll input
4. Multi-session tabs
5. Auto-reconnect with backoff
6. H.264 encoder (for future session recording)
7. Clipboard sync (bidirectional text + images)
8. Adaptive screen size
9. Retina support
